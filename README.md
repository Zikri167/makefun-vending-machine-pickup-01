One pickup line, spoken by a vending machine itself to a passing human — buttons, touch, and a hum, with the turn landing on the very last words. A single deterministic Node program writes the line to `/output/entry.txt` (1–200 characters, one line, no network).

## Run it

```sh
node main.ts
```
